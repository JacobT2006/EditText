## For Installation

Please download the latest version from the [Releases page](https://github.com/JacobT2006/EditText/releases/latest), then follow the instructions below for your current operating system:

- **macOS:** Open the downloaded `.dmg` file and move EditText to Applications.
- **Windows:** Run the downloaded setup `.exe` and follow the installer.
- **Linux:** Download the `.AppImage`, make it executable if needed, and open it.
